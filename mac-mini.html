Worth remembering

Eject before unplugging

Unsafe shutdowns on record: P310 56, 990 PRO 70, internal 11. All drives report no data errors.

Video is king: it gets the dock link first

Display traffic is reserved first on a Thunderbolt link. With the main monitor on this dock, writes to the drive behind it fall from about 3 GB/s to 1.5 GB/s. That is a fair trade for a streaming library, and it frees a port for DATA. The main screen goes dark if the dock disconnects.

One bus-powered enclosure

The mini runs only one bus-powered NVMe enclosure reliably. DATA's is that one. Media's runs on the Wavlink's own power supply.

Every lane has a job

All three back Thunderbolt ports are taken: the second monitor, the dock and DATA. DATA and Media no longer slow each other down.
